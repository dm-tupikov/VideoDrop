## VideoDrop 1.1.0 — новый интерфейс, один EXE

Портативная программа для скачивания видео и музыки с YouTube на Windows 10/11 x64.

### Что нового

- Новый интерфейс WPF: аккуратные карточки, боковая панель и переключатель «Видео / MP3».
- Кнопка скачивания и прогресс всегда под рукой — закреплены внизу окна.
- Поддержка масштаба Windows и изменения размера окна.
- Журнал под раскрывающейся панелью, понятные сообщения об ошибках.
- Исходники, инструкция сборки и автоматическая проверка сборки в GitHub Actions.

### Как запустить

Скачай **VideoDrop-Portable.exe** из Assets, положи в папку с правом записи и запусти. Вставь ссылку и нажми **Скачать**. По умолчанию: MP4 со звуком, до 720p. Есть MP3, несколько ссылок, плейлисты, выбор папки и обновление yt-dlp.

Все инструменты включены: yt-dlp 2026.10.26, FFmpeg/ffprobe 9.0.2 и Deno 2.9.8. Python и отдельная установка зависимостей не нужны. При первом запуске они распакуются в `VideoDrop-data` рядом с EXE.

### Файлы выпуска

- `VideoDrop-Portable.exe` — готовая программа для Windows x64, около 143 МБ.
- `VideoDrop-1.1.0-Windows-x64.zip` — программа, инструкция и лицензии одним архивом.
- `SHA256SUMS.txt` — контрольные суммы.
- `VideoDrop-Source-1.1.0.zip` — исходный код, документация и скрипты сборки.

Требуется встроенный .NET Framework 4.x (WPF) в Windows 10/11. Права администратора не нужны. EXE без цифровой подписи издателя.

Полная инструкция и сведения о сторонних лицензиях — в [README](https://github.com/dm-tupikov/VideoDrop#readme) и [THIRD_PARTY.md](https://github.com/dm-tupikov/VideoDrop/blob/main/THIRD_PARTY.md). Сохраняй материалы, на скачивание которых у тебя есть разрешение.
