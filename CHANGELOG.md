# История изменений

## 1.1.0 — 2026-11-05

- Новый интерфейс на WPF: карточки, боковая панель, переключатель MP4/MP3, стилизованный выбор качества.
- Кнопка загрузки и статус закреплены внизу окна и остаются доступны при прокрутке настроек.
- Масштабирование Windows и изменение размера окна без обрезания элементов.
- Журнал скрыт под раскрывающейся панелью и автоматически открывается при ошибках.
- Ошибки ввода и сети показаны прямо в окне.
- Сохранены портативность, выбор папки, несколько ссылок, плейлисты, отмена и обновление yt-dlp.
- Добавлены исходники, инструкция сборки, проверки, фиксированные зависимости и GitHub Actions.

## 1.0.0 — 2026-11-05

- Первая локальная версия с интерфейсом WinForms и зависимостями в одном EXE.
